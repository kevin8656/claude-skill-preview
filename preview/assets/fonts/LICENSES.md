# 預覽頁自帶字型授權

本資料夾的字型全部採 SIL Open Font License 1.1，授權全文隨檔散布，可自由使用、修改與再散布（不可單獨販售字型本身）。

| 字族 | 版權 | 授權全文 |
|---|---|---|
| Noto Sans TC | Adobe（保留字名 Source） | OFL-NotoSansTC.txt |
| Geist | The Geist Project Authors | OFL-Geist.txt |
| Geist Mono | The Geist Project Authors | OFL-Geist.txt |

說明：

- 這裡的檔案是子集化版本：字重裁到 400 到 700，Noto Sans TC 依常用程度切成四片（core、ext1、ext2、ext3），瀏覽器只下載頁面用到的分片。
- 字族名稱不含保留字名 Source。
- 原始字型：Noto Sans TC 取自 Google Fonts / Adobe Source Han Sans 專案；Geist 與 Geist Mono 取自 https://github.com/vercel/geist-font 。
