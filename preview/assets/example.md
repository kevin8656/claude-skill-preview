> 目前三件事分散在 LINE 群組、紙本筆記和 Excel，老闆每天要花將近 1 小時對資料。

> [!要你決定] 這頁請你做兩件事
> - 勾選下面「範圍確認」裡要做的項目
> - 按右上「複製全部」，把勾選結果和評論傳給我

```數字
6 週｜上線時間｜從簽約隔週開始算
3 個｜整合的資料庫｜訂單、庫存、排班
1 小時 → 10 分鐘｜每天對資料的時間｜依目前流程估算
48,000 元｜專案報價｜含 2 次教學
```

## 現在和改完後差在哪

```對照
現在 → 改完後
接訂單｜LINE 訊息一則一則翻 → 表單送出自動進訂單資料庫
看庫存｜打開 Excel 手動加減 → 訂單完成自動扣庫存
排班｜紙本筆記拍照傳群組 → 日曆檢視，每個人只看自己的班
```

## 系統怎麼組成

```架構
入口｜訂單表單、員工手機
↓ 資料寫進
資料庫｜訂單 → 庫存、排班
↓ 整理成
儀表板｜今日訂單、低庫存提醒、本週班表
```

## 時程

```時間軸
✅ 第 0 週｜需求訪談｜已完成，確認三大痛點
👉 第 1 週｜提案確認｜就是這一頁
第 2 到 3 週｜建置資料庫｜訂單與庫存先做
第 4 週｜排班與儀表板｜接上日曆檢視
第 5 週｜試營運｜店內實際跑一週
第 6 週｜教學與交接｜2 次線上教學
```

```步驟

```

## 範圍確認

### 一定要做

- [x] 訂單表單（顧客填完自動進資料庫）
- [x] 庫存自動扣減（訂單完成時扣原料）
